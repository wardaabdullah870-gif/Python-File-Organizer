# Automatic File Organizer

## Project Overview

Automatic File Organizer is a Python automation project that organizes files into separate folders based on their file extensions.

It uses Python's built-in `os` and `shutil` libraries to simplify file management.

## Features

- Automatically identifies file extensions.
- Creates category folders.
- Organizes documents, images, videos, music and archives.
- Moves unknown file types into an Others folder.
- Prevents overwriting existing files.
- Generates an organization summary.
- Allows users to select their own folder.
- Maintains an activity log.

## Technologies Used

- Python
- os
- shutil
- datetime

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python organizer.py
```

5. Enter the folder path you want to organize.

## Learning Outcomes

This project demonstrates Python file handling, directory management, automation, loops, dictionaries, conditional statements and exception-safe file organization.
